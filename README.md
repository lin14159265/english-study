# English Study · 语境阅读

基于 GitHub Pages 的 CET-4 词汇语境阅读器，保留原始 25 篇文章和 1000 个目标词，并支持 JSON 资料包导入与发布。

V3.1 提供 **书架 / 阅读 / 复习** 三个空间。每份文章资料包是一册有封面的书，点书进入章节目录；按书名、章节、主题、整本已读筛选，每本分别续读；复习包含到期安排、可解释阅读建议、统一义项档案和全部原记录。窄屏阅读页的空间入口在“更多”中。

V3.1 增加私人书架整理（置顶、归档、系列、显示书名及封面色调）、跨书正文与学习记录搜索、保留来源快照的义项辨析。义项辨析按原文标注核对，保留把握程度、疑义与跳过记录；不编造词义或宣称已经掌握。详见 [V3.1 使用与兼容说明](docs/v3-1.md)。

可从“复习 → 管理学习词库”导入扇贝主词库，保留原词性、释义与词条 / 义项 ID；只导入来源字段，私人熟悉度不入库、不公开。义项关联是可重建的视图，旧卡片和原句不改写。不确定的关联保持独立并可人工核查。实施与回退边界见 [V3 说明](docs/v3-study-spaces.md)。

网站内完整操作说明：**右上角更多（三点）→ 使用指南**。可搜索功能、按主题展开，包含日常阅读流程、全部现有工具及本机保存 / 云同步 / JSON 备份的区别；无需登录，离线缓存就绪后也可查阅。

阅读时按需查用义、核对译文；学习工具提供历史语境检索、本机文章纠错、可选理解小测、阅读任务队列和学习备份。义项卡、错句和作答保存原文快照，正文更新后不删除旧记录。辅助功能按需打开，无阅读滚动进度条。

选中正文中的句子可以暂存疑句、进入逐句练习并返回阅读现场；“更多 → 逐句练习”也能选择句子。理解草稿和可选分析保留当时快照。短回合复习集中练义项卡、错句与错题，刷新后继续；可选新语境使用同一记录义项的另一条真实例句，自评与客观题计分分开。

点词后的“纠正此处用义”支持轻量修改与补录；完整编辑器支持逐句译文和可选分析。本机人工核验标记在正文、词表义项、译文或解析改变后失效。目录支持日期、主题和已读筛选；多份 JSON 一起预览，任一文件出错时整批不写入。

“更多”里的保存状态在本机写入成功后显示已保存；失败会在阅读页提示，可重试或导出，多页面版本冲突会阻止旧页覆盖。首次联网准备完整应用缓存后可以离线阅读，本机导入与学习记录保存在浏览器；英文词典仍需联网。更新前先保存，缓存保持应用版本一致。完整备份包含疑句、待查笔记、复习历史和未完成回合，用于更换设备。

资料缺失或延迟加载时保留稳定文章键、已读及位置；资料就绪后重新定位。其他标签页更新后，无未保存修改的页面刷新本机状态；有未保存修改时保留冲突保护和备份出口。固定文章链接继续直达。阶段 1A 的数据兼容、验证范围、回退及后续同步设计见 [实施说明](docs/local-record-retention-1a.md)。

外页更新相关记录时，已打开的复习回合跟随新状态；过期的小测、编辑器及备份恢复预览需要重新核对。无关阅读位置更新不重置当前工具或写回旧缓存，也不全量读取资料包。外页 UI 刷新失败时暂停写入，通过阅读页提示或“更多 → 已保存 / 未保存 → 重试保存”重放；持续失败请重新打开，已提交本机记录保留。

使用和格式约定见 [IMPORT.md](IMPORT.md)，生成新资料使用 [配套提示词](downloads/article-generation-prompt.md) 和 [完整示例](downloads/pack-template.json)。个人数据本机优先，启用自动同步后同步到本人账号；文章改动先保存为个人修订，主动发布资料后才公开更新。也可用完整学习备份手动迁移。

静态 HTML / CSS / JavaScript，无依赖安装。运行检查：

```sh
node --test tests/*.test.cjs
```

## 续读与完整云同步

已加入稳定语义阅读锚点、继续阅读、Google 账号与 Firestore 的完整个人数据同步；本地 IndexedDB 与 JSON 备份仍为基础。未配置 Firebase 时阅读继续可用，不发送私人数据。配置与免费方案步骤见 [Firebase 启用说明](docs/firebase-setup.md)，兼容、冲突、隔离真机验收和回退边界见 [完整同步说明](docs/cloud-sync.md)。自动化使用合成数据验证；真实网络、账号与手机同步以实际验收为准。

## V2.0 阅读界面

目录改为按需打开，顶部保留目录、译文、Aa 和更多；标记已读放在文章末尾。暖色纸面与深色模式共用同一阅读布局，原有字号、行距和字体设置保留。宽屏页边展示本篇已有的生词与待回看记录、当前用义和个人批注；窄屏通过查词浮层及“更多 → 本篇生词与批注”访问。整篇与逐段译文默认收起。

完整功能入口、验证、独立预览及回退见 [V2.0 说明](docs/reader-v2.md)。V2.0 已发布，后续修改继续使用独立开发分支和 Pull Request。
