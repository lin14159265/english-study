# V3.1：整理书架、跨书搜索与义项辨析

## 使用

- 书架封面旁的三点打开“整理本书”。私人显示书名、封面色调、系列、置顶与归档均不改资料 ID 或文章 ID。默认只显示在书架上的书，置顶优先；可按最近阅读、书名排序。归档仅收起显示，不删除资料。原书名仍可搜索，“原资料管理”保留原导入管理入口。
- 书架、复习页底部和学习工具中的“跨书搜索”检查当前正文与译文、已保存生词、错句、待查笔记、疑句、阅读错题及任务；可按类型及书籍筛选、每次展开 50 条。归档资料在搜索范围内。仅在来源存在且快照引用可定位时跳转到段落。唯一移动的原句可重新定位，重复或改写后保留历史快照。完整小测作答历史和编辑器未发布草稿仍使用各自历史面板。
- 复习“今日安排”可开始 5 / 10 条义项辨析或继续未完成回合。需要先导入学习词库。只取当前文章的真实原句和唯一精确或人工确认的原义项关联；同词的完整释义、词性、来源 ID 保留。相同或互相包含的中文释义不作不同选项，不按逗号拆分；一句中同词混用不同意思的语境暂不出题。
- 先作答并选择有无把握，再核对。结果只表示与资料标注一致与否，资料标注也可能需人工核查。“有疑义”和“跳过”保存历史但不计分。没把握的答对不计作有把握的认识，客观比较与自评分别保存。来源更新使正在做的题停止按旧来源计分，不删除快照。旧回合不补造历史。
- 云同步面板可导出诊断 JSON：运行阶段、整轮与阶段时长、待提交数量、是否存在持久批次、联网状态及浏览器环境。不包含 UID、邮箱、文章、答案或私人学习内容。此功能用于真机排查，不代表已经查明旧手机同步异常原因。

## 数据与兼容

IndexedDB 仍为版本 3，不清空、不重建；JSON 备份仍为 version 1。扩展字段均可缺省，读旧数据不会创建假历史：

| 私人字段 | 身份与内容 | 冲突边界 |
| --- | --- | --- |
| `extra.bookSettings[packId]` | 显示书名、系列、色调、置顶、归档、更新时间 | 每本书整条原子记录；不同书可独立合并 |
| `extra.senseSession` | 回合 ID、完整题目快照、当前位置、选择与把握草稿 | 整个活动回合原子合并，冲突由用户选择 |
| `extra.senseAttempts[id]` | 回合与条目身份、来源快照、选择、把握、核对结果、时间 | 每次作答整条原子记录 |

沿用现有业务状态与 outbox 的同一事务、持久 operationId 确认、云端冲突双方副本和应用内存状态的消费者确认。新数据没有单独的 localStorage 或网络上传捷径。完整备份恢复、分卷、合并、恢复回退使用原流程；独立备份副本迁移书籍显示设置和辨析条目的文章/词条身份。

旧 V3 页面会保留未知字段的普通写入、云快照与完整替换恢复，但不理解 V3.1 的活动回合、辨析证据或新字段合并。包含新字段的备份冲突合并应使用 V3.1。不同版本同时在线时，活动回合及同书设置仍按整条冲突处理。

搜索索引只在本机由现有数据重建，不写进数据库或云端。按相关源引用变化失效；普通位置保存不重新读取私人资料包。正文搜索包括当前个人修订，不把被归档资料误作删除。实时搜索不发送查询到第三方。

## 验证与回退

### 本轮增补：可解释推荐与原义项覆盖

阅读推荐使用已保存且到期的确认义项、近几次反复误判、可定位的未理解错句和当前版本错题；当前版本难度反馈也参与排序。提供日常阅读、轻松一点、集中复测三种选择，最近 20 分钟读过的文章稍后排序，已归档书籍不主动推荐。轻松模式更倾向较短文章和标为轻松的当前版本；集中复测提高具体困难记录的优先级，也可推荐未收藏但已有辨析分歧记录、已到复测时间且来源可确认的义项；不因此自动收藏或建立义项卡。推荐规则是可解释的启发式，不是经过学习效果实验验证的算法。时间按 120 词/分钟粗估且不含查词，不代表实际阅读速度。选择为临时筛选，无新持久字段或自动已读行为。

词库语境覆盖按各原始词条/词典/义项身份保留完整中文释义和词性。只计当前加载文章中可唯一精确或人工关联的实际语境；归档不删除文章，因此仍计入覆盖。有歧义或选择保持独立的关联不强行归类。来源缺失或改写后，收藏与辨析中的旧语境可展示为历史快照，但不计当前覆盖；仍有当前语境的义项也可同时展示历史。所有原义项可按词库、状态、关键词或 ID 检索，每次 50 条；未关联和词库外用义单独显示。检查视图本机派生、按来源引用失效，不写进数据库或云端。导出完整缺口清单包含完整定义/POS/原 ID 和来源指纹，不受视图筛选影响；不包含原句、私人笔记、个人答案或学习时间。

修复：活动辨析题重新核查现有义项关联，另一标签页撤销/改动关联时停止旧题计分并保留选择快照。提交期间题目区暂时不可交互，无变化时不强制重绘，避免在状态已切题但题面尚未更新时操作旧题面；原生选择事件按回合与题号核对。浏览器测试同样按当前题面定位，再检查选择实际写入草稿。原单题历史保留，疑义和跳过仍不计分。

补充针对性回归：完整 6147 词 / 14556 条合成原义项的分页、原 ID 与定义保留、历史/当前覆盖边界、歧义关联与跨标签页撤销关联、完整缺口导出、已归档推荐过滤、过期难度反馈、近期访问、慢写入与快速进入下一题的交互。真实附件在本机检查，不提交到公开仓库；其原始公开文章范围的数据不能代表用户已导入私人文章后的覆盖情况。

增加针对性 Node 回归和 Chromium 交互测试：数据不改身份、缺失来源、重新定位、来源变化、计分完整性、把握程度、旧备份、新备份、独立副本、云端原子冲突；浏览器覆盖整理、归档与检索、两个标签页、恢复、辨析草稿、失败重试及诊断内容。继续运行原书架、复习工作区、辅助面板、模拟云同步和离线验收。
