# V2.0｜安静的电子书阅读器

V2.0 已随 PR #2 合并 main。后续优化继续采用独立分支与 PR。数据库仍为 IndexedDB v3，JSON 学习备份仍为 version 1；未改 Firestore 结构、规则或本人账号配置。

| 阅读操作 | V2 入口 |
| --- | --- |
| 换文章、筛选、继续阅读 | 左上角目录抽屉 |
| 核对译文 | 顶部译文展开全部；段落“译”展开一段 |
| 查本次用义、收藏 | 点击目标词；宽屏页边、窄屏浮层 |
| 猜义、自评、允许义项、历史、纠错 | Aa 中开启先猜；用义面板的自评与更多 |
| 个人批注与待回看 | 已有记录显示在页边；更多 → 本篇生词与批注 |
| 留疑句、逐句理解 | 选中原句；或更多 → 逐句练习 |
| 标记已读 | 正文末尾的小按钮，不自动切换文章 |
| 小测、任务、复习、编辑、导入、备份、云账号 | 更多 |
| 字号、行距、字体、主题、专注 | Aa |

## 内置使用指南（2026-10-13）

更多 → 使用指南：13 个主题，说明日常阅读、续读与设置、具体义项收藏、疑句 / 错句、复习、小测、任务、检索与待查笔记、修订核验、私人资料、完整备份、云同步及保存离线。可搜索功能并展开详细步骤；快速定位只滚动指南，不改变文章 URL。入口不占正文或固定工具栏，关闭后返回更多，所有指南状态只存在于页面内存。模块纳入离线缓存。

V2 隐藏旧底栏后，任务区不再把已隐藏的旧完成按钮当作可用入口；正在进行的任务在正文末尾显示原有的完成操作。普通文章的已读按钮仍不自动切换文章。

## 生词标记与最近阅读（2026-10-13）

- Aa → 正文词汇标记：全部目标词 / 仅我的生词 / 不标记。默认继续尊重旧版的强调开关；不自动替用户切换。生词来自实际已收藏义项卡（含因模糊或义项误判而加入的卡），按 wordKey + 实际用义匹配。同词另一义项不会连带标记；移除某张卡后，只有该义项已无其他收藏卡时才取消标记。未标记的目标词仍可点选和通过键盘打开。
- 目录抽屉：最近阅读最多五篇，与全部文章共用可滚动区域。按稳定文章键去重，点选恢复对应的语义锚点 / 旧像素位置；使用搜索或筛选时隐藏最近阅读区，避免混入筛选外的结果。缺失资料显示历史条目，加载后恢复为有效链接。固定链接的直达语义及原续读记录保持不变。
- 兼容：新增可选 reader.settings.highlightMode 和 reader.visitKeys（稳定键 → 访问毫秒时间），保留旧 highlight 布尔字段。最近阅读也使用已有 anchorKeys.updatedAt；旧像素位置没有日期时只补已知续读项，不编造其余文章的访问顺序。visitKeys 与现有阅读检查点一起提交，不额外增加滚动写入频率。跨标签页重载后重新投影生词与最近阅读。
- version 1 备份仍可导出、恢复、合并和回退。访问时间只合并每篇最大值，不改变已读状态和阅读位置；独立资料副本同时改写访问键。完整同步采用相同的单调时间合并，不因此触发学习内容冲突。未增加新数据库或版本升级。
- 回退：撤销本次 PR 的代码与缓存版本，不清除数据；旧客户端保留新增的可选字段，按原 highlight 显示（saved 模式回退为全部目标词），再次升级即可恢复三种模式。

验证：`node --test tests/*.test.cjs`，以及可选 `node tests/reader-personal-browser.cjs`。浏览器用公开文章与合成学习记录运行在独立 loopback 源，Firebase 禁用，不接触正式站的私人数据。覆盖三个模式、同词不同义、实时收藏/移除、跨标签页、最近五篇及位置恢复、缺失/延迟资料、旧备份和桌面/手机/平板的浅深色布局。输出证据默认位于临时目录。真实 Safari 仍需真机检查。

## 次级面板统一（2026-10-13）

- 新增 `reader-panels.css`，仅作用于 V2 弹窗，沿用正文的浅色 / 护眼 / 夜间色彩。统一标题、留白、控件、状态文案、折叠区和按钮；长面板标题及关闭按钮保持可见。移动表单保持 16 px 输入字号和 44 px 主要触摸控件。
- “更多”将原有入口整理为本篇工具、学习与复习、资料与设备。移动现有 DOM 控件，不克隆 ID 或替换监听器，云同步状态、保存状态及同步期间的锁定仍作用于原节点。未删去任何工具，阅读视图及其键盘导航保持。
- Aa 将阅读辅助放在“完成”之前；辅助按钮明确使用 `type=button`，防止在对话框表单内意外提交。猜义、字体、主题、生词标记均沿用原保存机制。
- 修复旧“学习回顾”点击事件被误当作仅刷新参数、导致面板未打开的问题；后台刷新仍保留原行为。
- 数据结构、IndexedDB、云协议、Firebase 配置和安全规则均未变。缓存版本为 `20261013-panels`，新增 CSS 包含在离线 shell 和独立预览白名单中。回退时撤销本次 UI 提交并更新缓存，不清理数据库。

针对性验收：`node tests/reader-panels-browser.cjs`，覆盖 14 个入口、真实搜索、编辑草稿及备份下载、原阅读视图、Aa 设置、键盘折叠、长面板关闭、手机 / 平板浅深色与横屏。测试使用隔离源，Firebase 禁用。真实 iOS Safari 未以视口模拟替代。浏览器截图与日志保存在临时目录，不提交私人记录。

## 次级面板返回修复（2026-10-13）

从“更多”打开的二级面板，X、Esc、背景点击和左侧返回按钮均返回上一级，恢复原菜单的滚动位置与触发控件焦点。支持“更多 → 导入与资料 → 备份”、云账号 / 保存状态 → 备份等多层路径；页头仅显示返回箭头与当前标题，原层级仍由临时导航栈维护。根面板关闭后回到阅读。正文查词、末尾小测等直接入口不附加“更多”父级。回到原句、开始阅读任务或选择新文章会明确结束面板导航，避免旧菜单意外重现。

新增 `panel-navigation.js` 管理原生 dialog 的临时 UI 栈，不写 IndexedDB 或 JSON 备份。重复刷新同一个编辑器不重复入栈；原生 dialog 表单提交和现有保存后关闭同样遵守返回逻辑。原有状态重载、同步锁定与备份操作保留。新的开关控件包裹原 checkbox，保留其 ID、监听器、键盘操作和表单语义；高对比度模式回退为原生控件。

缓存版本为 `20261013-panel-return`。模块纳入离线缓存与隔离预览。新增验收覆盖 14 个入口逐一返回、三层 X / Esc / 返回按钮、焦点和滚动恢复、正文直达、跳回原句、重复编辑器刷新、原生表单关闭、触摸布局与开关，以及原有云同步失败恢复。撤销此 UI 提交与缓存版本即可回退，不清理学习数据。

页边只投影已有个人记录，无示例记录、独立笔记数据库或新的数据格式。只有稳定文章键、段落和保存原句均对应当前正文时才显示批注。旧原句失配时仍可在完整记录中查看历史快照，不会贴到新的无关段落。普通阅读状态更新只比较学习对象、扩展对象及文章版本，不全量读取或序列化资料包。

## 三设备精修（2026-10-12）

- 电脑：正文宽度随已有字号合理收紧，正文与左右记录整体居中，页边距离纸面 36 px；覆盖 2560×1600 及 125%/150%/175% 缩放等效 CSS 视口，也检查半屏窗口。
- iPhone 12 Pro Max：428×926 / 926×428 CSS 视口、DPR 3 的 Chromium 触摸模拟。加入安全区域与 VisualViewport；浮层选择避开所点文字的可用空间，内部滚动。地址栏/键盘造成的高度变化保留查词及输入；宽度变化继续使用原阅读锚点恢复。
- iPad 第九代：810×1080 / 1080×810、DPR 2 的触摸模拟，另测 535 和 375 px 分屏窗口。保留单栏，平板标题与留白单独调整；触摸按钮至少 44 px，文本输入 16 px。触摸打开目录先聚焦关闭按钮，避免自动弹出搜索键盘。
- 排版与译文：长标题平衡换行，正文与译文处理长词换行、段距和层次；保留原字号、字体和行距，不重置旧偏好。
- 页边：滚动停止 260 ms 后，优先展示当前及相邻段落中仍能核对原句的卡；未匹配的历史卡保留。排序不修改收藏记录，不写数据库，也不扫描或序列化全部资料包。

这里的屏幕缩放、旋转、键盘和后台事件是自动化模拟，不代表实体 Windows 或 iOS Safari 验收。实际布局依据 CSS 可用窗口，不能把屏幕物理像素当作浏览器宽度。

## 隔离预览

[打开独立 V2 预览](https://english-study-v2-reader-preview.grandvole9.chatgpt.site/#article-02)：仅本人可访问，包含公开文章，关闭 Firebase；其 origin 与正式站不同。本机记录在预览环境中产生，不会进入正式云端。初次左右为空是正常的，收藏词、保存错句后才出现真实页边记录。

真机检查：打开预览 → 点词并收藏 → 更多中选择逐句练习并保存理解/错句 → 返回阅读 → 展开和收起逐段/全文译文 → Aa 调整字号及深色主题 → 在末尾标记已读 → 关闭后重开并从目录继续 → 横竖屏切换。可在预览里恢复已导出的完整备份，再核对旧记录；不要清除正式网站数据。

本轮集中真机清单：iPhone Safari 滚动令地址栏伸缩，点词后输入猜义并收起键盘，再横屏、切后台后返回；确认浮层可关闭、原句附近仍能续读。iPad 横竖屏并尝试分屏，检查段落译文、查词和更多中的完整记录。电脑最大化、半屏、改变缩放；确认页边仍靠近纸面，原字号与位置保留。

如需使用本人已有 Firebase Hosting 的隔离 channel，解压本分支后双击 `scripts/preview-reader-v2.cmd`。需要此前已登录的 Node/Firebase CLI；脚本只部署 `v2-reader` 临时 channel，不部署 live，Firebase 配置在生成目录中置空。`node scripts/prepare-reader-v2-preview.cjs` 也会生成可离线打开的独立 HTML，并使用独立本机存储名称。生成内容只读取白名单公开应用文件，不读取浏览器配置、私人备份或测试结果。
