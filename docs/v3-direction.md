# V3.0 方向草案：从语境阅读器到个人语境学习系统

这是产品方向草案，尚未启动 V3 重构。V2 继续保留安静阅读、私人资料、完整同步和 JSON 备份。

## 当前基础与实际差距

现有功能已经包括续读、生词义项卡、错句、小测、短回合、同义项换语境、历史检索和学习回顾。`experience-core.js` 已按复习记录时间和部分自评排序；V3 不应重新实现这些功能。

目前卡片身份包含资料批次、实际中文用义和原句；同词同义在不同资料中可以形成多张卡。短回合按记录选题，尚无贯穿资料的统一义项学习档案和可解释的到期复习模型。阅读、复习和资料管理的入口仍主要集中在“更多”。

## 建议的三个核心变化

| 方向 | 实际改变 | 验收例子 |
| --- | --- | --- |
| 统一义项档案 | 在保留原卡片与历史快照的基础上，以核实的词库词条 / 义项 ID 建立跨资料关联，汇总真实学习证据 | 同一义项在三篇文章中出现时可查看同一学习档案；另一义项和另一词性不会误合并 |
| 可解释的复习与阅读安排 | 从现有短回合升级到义项级到期复习与阅读建议，说明依据、支持跳过和手动调整 | 看得到“为什么今天复习”；先独立判断，再换真实语境验证；自评与客观作答分开记录 |
| 书架、阅读、复习三个清晰空间 | 按资料包、主题、系列组织文章；阅读界面保留电子书风格；学习计划和复杂管理集中到专门空间 | 日常只需选书、续读或复习；直接文章链接仍直达，正文没有常驻学习仪表盘 |

统一义项不能只靠中文字符串相近。需保留词性、原始来源 ID、原始释义和映射依据；不确定关联标为待核查，默认保持独立。旧卡片不自动删除或覆盖，新索引能从旧记录重建。

安排模块应使用历史理解、错误类型、近期复习结果和文章用义覆盖，保持解释可见；不把阅读次数或单次“认识”当作掌握。已有同义项换例句是起点，新语境验证与到期调度是进一步的变化。

## 学习设计依据与边界

2024 年的一项原始研究以外语词汇及其提示句进行实验：在检索练习中改变提示语境，能够改善其任务中的词义记忆表现。研究所用材料、测试和延迟与完整四级阅读不同，因此这里据此提出产品实验，不能承诺四级分数收益。

- 原研究：The role of variable retrieval in effective learning，PNAS，DOI 10.1073/pnas.2413511121。
- 摘要与方法概述：https://pubmed.ncbi.nlm.nih.gov/39453748/

## 实施边界与顺序

1. 先补齐 V2 的真实设备完整同步与离线恢复验收，包括私人资料、个人修订和全部学习记录。现有自动化及模拟视口不能代替真机验收；此前手机长期同步提示的排查仍未结束。
2. 先完成统一身份与只读学习档案，再加入复习安排和学习空间。每项都有独立分支、旧备份兼容、增量迁移和回退验证。
3. 默认沿用原生 JavaScript、GitHub Pages、IndexedDB 和 Firebase，不因版本号引入大型框架或整体重写。
4. AI 辅助理解反馈可在核心稳定后评估：答案仍受原词库义项约束，区分原文证据、参考译文和建议；需决定数据发送范围、质量核验及费用后才接入。
5. 所有私人记录与索引均参加最终完整同步；保留完整 JSON 备份、恢复预览、冲突副本和回退。

成立标准是用户能持续完成“读文章 → 留下具体义项 / 难句 → 按时再判断 → 换语境验证 → 选择下一篇”的过程。新的配色、按钮或更多统计本身不足以构成 V3.0。
