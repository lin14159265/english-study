# 上传阅读资料

在这个文件夹点击 **Add file → Upload files**，上传网站预览通过的 `.json` 资料包，然后 **Commit changes** 到 `main`。

只需上传资料文件，无需修改网页或目录。GitHub Pages 发布完成后，网站会自动加载新资料。资料文件名请用英文、数字和短横线，例如 `2026-10-01-day01.json`。同一资料包修改时保持 `id`、文章 `id` 和文件名不变；新批次使用新的 `id`。

不要修改 `index.json`，它会在发布时自动生成目录。不要给资料 JSON 加 YAML front matter（文件应直接以 `{` 开始）。所有文件都是公开的，请只上传学习资料。
