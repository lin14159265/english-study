# English Study · 语境阅读

基于 GitHub Pages 的 CET-4 词汇语境阅读器，保留原始 25 篇文章和 1000 个目标词，并支持 JSON 资料包导入与发布。

阅读时按需查用义、核对译文；学习工具提供历史语境检索、本机文章纠错、可选理解小测、阅读任务队列和学习备份。义项卡、错句和作答保存原文快照，正文更新后不删除旧记录。辅助功能按需打开，无阅读滚动进度条。

点段落旁的“选句”可以暂存疑句、进入逐句练习并返回阅读现场；理解草稿和可选分析保留当时快照。短回合复习集中练义项卡、错句与错题，刷新后继续；可选新语境使用同一记录义项的另一条真实例句，自评与客观题计分分开。

点词后的“纠正此处用义”支持轻量修改与补录；完整编辑器支持逐句译文和可选分析。本机人工核验标记在正文、词表义项、译文或解析改变后失效。目录支持日期、主题和已读筛选；多份 JSON 一起预览，任一文件出错时整批不写入。

顶部状态在本机写入成功后显示已保存；失败可重试或导出，多页面版本冲突会阻止旧页覆盖。首次联网准备完整应用缓存后可以离线阅读，本机导入与学习记录保存在浏览器；英文词典仍需联网。更新前先保存，缓存保持应用版本一致。完整备份包含疑句、待查笔记、复习历史和未完成回合，用于更换设备。

资料缺失或延迟加载时保留稳定文章键、已读及位置；资料就绪后重新定位。其他标签页更新后，无未保存修改的页面刷新本机状态；有未保存修改时保留冲突保护和备份出口。固定文章链接继续直达。阶段 1A 的数据兼容、验证范围、回退及后续同步设计见 [实施说明](docs/local-record-retention-1a.md)。

外页更新相关记录时，已打开的复习回合跟随新状态；过期的小测、编辑器及备份恢复预览需要重新核对。无关阅读位置更新不重置当前工具或写回旧缓存，也不全量读取资料包。外页 UI 刷新失败时暂停写入，通过顶部“重试保存”重放；持续失败请重新打开，已提交本机记录保留。

使用和格式约定见 [IMPORT.md](IMPORT.md)，生成新资料使用 [配套提示词](downloads/article-generation-prompt.md) 和 [完整示例](downloads/pack-template.json)。个人数据保存在当前浏览器；改文保存本机修订，导出后上传 GitHub 才公开更新。换设备用学习备份迁移。

静态 HTML / CSS / JavaScript，无依赖安装。运行检查：

```sh
node --test tests/*.test.cjs
```

## 续读与完整云同步

开发版加入稳定语义阅读锚点、继续阅读、Google 账号与 Firestore 的完整个人数据同步；本地 IndexedDB 与 JSON 备份仍为基础。未配置 Firebase 时阅读继续可用，不发送私人数据。配置与免费方案步骤见 [Firebase 启用说明](docs/firebase-setup.md)，兼容、冲突、隔离真机验收和回退边界见 [完整同步说明](docs/cloud-sync.md)。真实账号配置与真机验收完成前，不应将自动化测试结果当作正式云同步已上线。
