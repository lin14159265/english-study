# V3：书架、义项档案与可解释复习

## 使用

- 宽屏顶部选择书架、阅读、复习。手机及宽度不超过 1100 CSS px 的阅读页把空间切换放在“更多”；阅读正文没有常驻仪表盘。书架和复习页显示主导航。
- 书架按标题、资料批次、主题、已读筛选；续读使用原稳定文章键及语义锚点。目录、最近阅读和固定文章链接继续有效。默认启动仍遵循 V2 的直达 / 续读顺序。
- 复习分为今日安排、义项档案、全部记录。全部记录继续使用原义项卡、错句、阅读错题的检索、分页和撤销。
- “管理学习词库”导入扇贝 JSON，预览后保存。保留原单词、词性、中文释义及词条 / 义项 / 词典 ID；不拆中文逗号，不导入熟悉度、音标、学习时间或来源列表。词库不产生文章，不成为公开文章包。
- 来源与释义唯一精确匹配时建立只读关联；同词另一意思、另一词性、多来源歧义或近义中文译法不猜测。可以在档案中依据原句明确关联，或选择独立。旧卡片 ID、原句、允许义项和自评不改写。
- 删除文章、修订原文或更新词库不删除学习快照。明确关联的原 ID、词性或释义变化后，保留原关联快照并待核查。这里只保留已有记录的证据，不补造早期作答历史。

## 到期规则

首次判断立即安排；仍模糊 1 天后核对，误判 10 分钟后再测。连续认识判断至少间隔 20 小时才推进到 1、3、7、14、30 天。错误客观选项即使自评认识仍算误判。一次复习同时写入的回合结果及点词自评只算一份判断证据。设备时间明显偏前的记录在视图中标注，原时间不修改。

一次选 5、10 或 20 项，每个已关联义项选一个原记录；待核查记录各自独立。新语境必须能匹配同一来源义项，否则使用收藏时快照。已有回合优先续做，草稿和结果沿用原存储及同步。可手动暂缓 1 天或提前复习；暂缓不算认识或作答。阅读建议只根据真实文章中到期的已关联义项及未读状态解释排序。

## 兼容与同步

IndexedDB 保持版本 3，不清空、不重建。JSON 学习备份保持 version 1。可选元数据均在 `state.extra`：

| 字段 | 身份与用途 |
| --- | --- |
| `studyLexicons` | 来源 ID → 最小词库，含内容标识及原词条 / 义项 ID |
| `studyBindings` | 原卡片或自评记录 ID → 人工关联快照 / 独立选择 |
| `studyDeferrals` | 派生义项身份或原错句 / 错题 ID → 手动暂缓时间 |

档案、到期队列及建议均重建，不写新的“掌握率”。未收藏的点词自评可以查历史，但不会自动重新创建已删除卡片或安排未收藏词。

新字段进入现有 IndexedDB 工作区与待同步队列事务，沿用云端分块快照和持久 operationId 确认；没有上传单个超大 Firestore 文档。各来源词库、每条人工关联及暂缓记录为原子冲突单位，不能把两个设备的 ID、词性和释义拼接成混合关联。已有冲突预览、双方副本、失败重试与 JSON 回退保留。云端合并后，原 reader 的已确认刷新消费者更新正在运行的三个空间；失败仍暂停写入并允许重试。

兼容边界：V3 读取旧 v1 备份，并支持新字段的合并、替换和分卷；V2 会在普通保存及完整替换恢复中携带未知字段，但旧 V2 的“合并恢复”没有这些新映射的专门合并规则。需要合并包含词库的备份时使用 V3。不要把旧客户端的合并恢复称作完整向后兼容。

## 回退

发布前完整导出学习 JSON。回退界面时保留 V3 的 `study-core.js`、`workspace-core.js` 和 `sync-core.js` 兼容读取及原子合并代码，只恢复 V2 的导航 / 显示模块；词库和人工关联仍能备份及同步，不删除 extra 字段。完整源码回退至 V2 前先导出新版完整备份，关闭其他页面，保留 IndexedDB v3；使用 V3 执行新字段的备份合并。旧数据库 v2 版本不能覆盖当前 v3。

## 验证范围

自动测试使用公开文章及合成记录，包含与原词库同规模的 6147 词 / 14556 义项。原附件仅在离线 Node 环境核对解析计数和成本，没有上传到 GitHub 或测试云端。最小来源数据约 1.40 MB；本次环境解析约 31 ms，首次建立索引约 11 ms，1000 次缓存访问约 1 ms，不能当作手机性能保证。索引按词条查找并按内容标识缓存；只读 UI 不反复复制完整词库。现有工作区持久提交仍复制完整本地快照，并未为了 V3 重构事务模型。

Chromium 检查书架 / 阅读切换位置、词库导入、人工关联、到期回合、草稿续做、两个标签页、完整备份、新浏览器恢复、保存失败、窄屏及深色外观。既有面板、云同步适配器和 Service Worker 离线测试继续运行。布局参考与实际界面同用暖纸色、衬线标题、简洁文章行；真实标题 / 中文标题替代概念图示意说明，筛选和元数据按真实资料显示。

仍须真机验收：iPhone 12 Pro Max Safari、iPad 9 Safari、电脑实际账号间的完整同步与离线恢复。模拟视口和假云适配器不能证明 Google 登录、国内网络或此前手机长期“同步中”问题已经解决。此项继续保留为完整项目验收要求。没有启用计费、修改 Firebase 安全规则或上传真实学习数据。
