# V2.0｜安静的电子书阅读器

本轮仅调整界面与相关交互，基于完整同步 PR #2 开发。PR 以该开发分支为基线，未合并 main。数据库仍为 IndexedDB v3，JSON 学习备份仍为 version 1；未改 Firestore 结构、规则或本人账号配置。

| 阅读操作 | V2 入口 |
| --- | --- |
| 换文章、筛选、继续阅读 | 左上角目录抽屉 |
| 核对译文 | 顶部译文展开全部；段落“译”展开一段 |
| 查本次用义、收藏 | 点击目标词；宽屏页边、窄屏浮层 |
| 猜义、自评、允许义项、历史、纠错 | Aa 中开启先猜；用义面板的自评与更多 |
| 个人批注与待回看 | 已有记录显示在页边；更多 → 本篇生词与批注 |
| 留疑句、逐句理解 | 选中原句；或更多 → 逐句练习 |
| 标记已读 | 正文末尾的小按钮，不自动切换文章 |
| 小测、任务、复习、编辑、导入、备份、云账号 | 更多 |
| 字号、行距、字体、主题、专注 | Aa |

页边只投影已有个人记录，无示例记录、独立笔记数据库或新的数据格式。只有稳定文章键、段落和保存原句均对应当前正文时才显示批注。旧原句失配时仍可在完整记录中查看历史快照，不会贴到新的无关段落。普通阅读状态更新只比较学习对象、扩展对象及文章版本，不全量读取或序列化资料包。

## 三设备精修（2026-10-12）

- 电脑：正文宽度随已有字号合理收紧，正文与左右记录整体居中，页边距离纸面 36 px；覆盖 2560×1600 及 125%/150%/175% 缩放等效 CSS 视口，也检查半屏窗口。
- iPhone 12 Pro Max：428×926 / 926×428 CSS 视口、DPR 3 的 Chromium 触摸模拟。加入安全区域与 VisualViewport；浮层选择避开所点文字的可用空间，内部滚动。地址栏/键盘造成的高度变化保留查词及输入；宽度变化继续使用原阅读锚点恢复。
- iPad 第九代：810×1080 / 1080×810、DPR 2 的触摸模拟，另测 535 和 375 px 分屏窗口。保留单栏，平板标题与留白单独调整；触摸按钮至少 44 px，文本输入 16 px。触摸打开目录先聚焦关闭按钮，避免自动弹出搜索键盘。
- 排版与译文：长标题平衡换行，正文与译文处理长词换行、段距和层次；保留原字号、字体和行距，不重置旧偏好。
- 页边：滚动停止 260 ms 后，优先展示当前及相邻段落中仍能核对原句的卡；未匹配的历史卡保留。排序不修改收藏记录，不写数据库，也不扫描或序列化全部资料包。

这里的屏幕缩放、旋转、键盘和后台事件是自动化模拟，不代表实体 Windows 或 iOS Safari 验收。实际布局依据 CSS 可用窗口，不能把屏幕物理像素当作浏览器宽度。

## 验证

2026-10-12 运行源码：228 项 Node 自动检查；Chromium 153 共 43 组（原 25 组、V2 界面 12 组及三设备 6 组）。覆盖旧备份、缺失/延迟资料、双标签页、语义续读、SW 更新及离线、完整模拟同步、词义/猜义、批注修改、三设备及分屏无溢出、浮层避让、连续查词、收藏反馈、16 px 输入、夜间文字对比及模拟后台即时检查点。原有实际 SDK + Firestore 模拟器 5 组保留；该规则验收于 2026-10-11 通过，本轮未改规则或同步存储核心。

新增故障检查：页边刷新消费者失败时，同步/外页刷新保留数据库 head 并暂停编辑，重试后恢复；单纯本机页边投影失败时准确说明“记录已保存、显示刷新失败”，不误报数据库丢失，也不会抛出未捕获页面异常。云端合并期间“更多”里的保存重试与云账号仍能打开，其他修改入口锁定。

视觉对照已检查批准概念图及实际 1536×1024 截图：纸面配色与平面布局、衬线标题、正文宽度与留白、左右页边、顶部四入口及无底部导航，另检查 2K、平板和手机日夜截图。顶部文案没有新增。批准的精修差异为标题平衡换行、纸面随已有字号收紧、页边贴近纸面；原默认 21 px 与已存偏好保持，原概念/上一轮部分截图的 26 px 不会强制写给用户。按批准风格完成实图比对，未发现遮挡、溢出或其他未解释的布局偏差。

复跑：`node --test tests/*.test.cjs`。浏览器脚本为 `tests/browser-acceptance.cjs`、`reader-position-browser.cjs`、`cloud-browser.cjs`、`firebase-loader-browser.cjs`、`reader-v2-browser.cjs`、`reader-device-browser.cjs`。外部 Playwright、Chromium、历史基线和官方 SDK 测试副本通过原有 `ENGLISH_STUDY_*` 环境变量传入；截图和合成个人记录输出到仓库外。当前 Browser 插件和 WebKit 可执行文件均不可用，使用现有 Playwright/Chromium；没有安装新浏览器或项目依赖。原等待状态测试改用可控时钟，避免繁忙机器上固定 25 ms 等待的竞态；生产同步计时逻辑未改。

模拟云认证/后台与 Firestore 模拟器不等于真实 Google 登录或手机同步验收。本轮未重新认证生产云端，未解决之前暂停排查的手机长期同步提示。Android、iPhone 和平板的系统浏览器尚需真机体验。

## 隔离预览

[打开独立 V2 预览](https://english-study-v2-reader-preview.grandvole9.chatgpt.site/#article-02)：仅本人可访问，包含公开文章，关闭 Firebase；其 origin 与正式站不同。本机记录在预览环境中产生，不会进入正式云端。初次左右为空是正常的，收藏词、保存错句后才出现真实页边记录。

真机检查：打开预览 → 点词并收藏 → 更多中选择逐句练习并保存理解/错句 → 返回阅读 → 展开和收起逐段/全文译文 → Aa 调整字号及深色主题 → 在末尾标记已读 → 关闭后重开并从目录继续 → 横竖屏切换。可在预览里恢复已导出的完整备份，再核对旧记录；不要清除正式网站数据。

本轮集中真机清单：iPhone Safari 滚动令地址栏伸缩，点词后输入猜义并收起键盘，再横屏、切后台后返回；确认浮层可关闭、原句附近仍能续读。iPad 横竖屏并尝试分屏，检查段落译文、查词和更多中的完整记录。电脑最大化、半屏、改变缩放；确认页边仍靠近纸面，原字号与位置保留。

如需使用本人已有 Firebase Hosting 的隔离 channel，解压本分支后双击 `scripts/preview-reader-v2.cmd`。需要此前已登录的 Node/Firebase CLI；脚本只部署 `v2-reader` 临时 channel，不部署 live，Firebase 配置在生成目录中置空。`node scripts/prepare-reader-v2-preview.cjs` 也会生成可离线打开的独立 HTML，并使用独立本机存储名称。生成内容只读取白名单公开应用文件，不读取浏览器配置、私人备份或测试结果。

## 兼容与回退

修改涉及 `index.html`、`reader.js`、三份新增布局文件、`cloud-sync.js` 的恢复入口锁定选择器、Service Worker 文件清单、测试、预览脚本及说明。原存储、导入、学习与同步核心保留。新增前端文件与 index/SW 版本一致，避免离线漏载布局。

正式上线前先导出并验证完整 JSON 备份，再批准合并/部署。需要回退时撤销 V2 UI 提交，保留 PR #2 的 IndexedDB v3 与完整同步存储层；刷新 SW 回到兼容的 UI，不删除数据库，不直接换回 V1.1 的旧数据库代码。预览本机产生的记录若需要保留，先另行导出；不会自动迁回正式网站。
